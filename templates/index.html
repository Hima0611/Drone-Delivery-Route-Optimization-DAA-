Design and Analysis of Algorithms (DAA) Report

Project Title: Design and Analysis of an Optimized Drone Delivery Route Using Graph Algorithms

1. Problem Formulation & Graph Modeling

The drone delivery network is represented as a Weighted Undirected Graph G = (V, E):

  • Vertices (V): Represent physical physical locations including the dispatch Warehouse, Customer A-F destinations, and Charging Station waypoints.
  • Edges (E): Represent navigable flight paths connecting two locations.
  • Edge Weights w(u, v): Non-negative Euclidean distance in kilometers (km) between location u and location v.

2. Dijkstra's Shortest Path Algorithm (Greedy Paradigm)

Dijkstra's algorithm employs a Greedy Choice Strategy to compute single-source shortest paths on non-negatively weighted graphs. At each step, it selects the unvisited node with the smallest tentative distance.

Edge Relaxation Condition:

if d[u] + w(u, v) < d[v]:
    d[v] = d[u] + w(u, v)
    pi[v] = u

3. Algorithm Complexity Analysis

  • Time Complexity: O((V + E) log V)
    • Min-Heap Extract-Min is called V times: O(V log V)
    • Edge Relaxation / Push operations executed at most E times: O(E log V)
    • Total Time Complexity = O((V + E) log V) (simplifies to O(E log V) for connected graphs).
  • Space Complexity: O(V + E)
    • Adjacency List storage: O(V + E)
    • Priority Queue & distance array memory: O(V)

4. Battery Feasibility Model

Energy consumption is calculated linearly as Battery Required = Distance × Burn Rate (%/km). A route is declared ✓ Route Feasible if available battery capacity satisfies Battery Available >= Battery Required.
